## Description
Let users create custom tabs that combine and filter content across all data types. A researcher interested in financial risk could create a tab that shows only high-priority gaps, contradictions related to money, entities with financial roles, and sources with credibility concerns. These custom compositions can be saved, shared as templates, and evolve into community-curated research lenses for specific use cases like due diligence, competitive intel, or investigative journalism.

## Reasoning
Fixed tabs force users into predetermined workflows. A composition engine would let each user build their optimal research view based on their specific needs. Shared templates would create a community-driven library of research lenses, making the platform increasingly valuable as more users contribute.
