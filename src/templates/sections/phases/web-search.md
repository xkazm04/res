## Phase 2: Web Search Execution

Execute the search queries you generated using the WebSearch tool.

### Instructions
1. Execute each query using the WebSearch tool
2. For each search, scan the top 5-10 results
3. Open and read relevant pages to gather detailed information
4. Track which sources you've consulted

### Search Execution Guidelines
- **Maximum searches:** {{maxSearches}}
- **Focus on:** Primary sources, recent publications, authoritative domains
- **Avoid:** Paywalled content, obviously promotional material, outdated information

### Source Selection Criteria
Prioritize sources that are:
- From recognized domains (.gov, .edu, established news, industry analysts)
- Recently published (prefer last 12 months unless historical context needed)
- Written by identified authors or organizations
- Cited by other sources

### During Search
As you search, mentally note:
- Key facts and claims you're finding
- Source quality indicators
- Potential contradictions between sources
- Gaps in available information

### Output for This Phase
No explicit output needed. Proceed to credibility assessment after completing searches.
